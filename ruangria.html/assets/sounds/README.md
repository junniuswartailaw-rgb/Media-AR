# Ganti backsound

Salin file MP3, WAV, atau OGG ke folder ini, misalnya `backsound.mp3`. Buka file `music-config.js` di folder utama dan isi:

```js
defaultSrc: './assets/sounds/backsound.mp3',
```

Simpan lalu buka kembali `index.html`. Tekan tombol musik untuk mendengarkan. Pilihan musik dari dalam aplikasi disimpan di browser perangkat itu saja.
